# Site institucional do Mapa_AF

Páginas estáticas para a apresentação do aplicativo e sua Política de Privacidade. O GitHub Pages publica os arquivos da raiz da branch `main`.

- `index.html` contém a página inicial.
- `privacidade/index.html` contém a Política de Privacidade.
- `estilos.css` contém os estilos das duas páginas.

Para atualizar o contato público ou a política, edite as páginas correspondentes e revise o conteúdo antes de publicar.
